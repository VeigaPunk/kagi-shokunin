## Minimal change proposal (not implemented)
1. **Tokenizer:** keep whitespace splitting and brace expansion. Add a narrow quoted-list step that recognizes a bracketed list of quoted items and splits only commas between a closing quote and the next opening quote (allowing optional whitespace). Remove the enclosing list brackets for those items, then run each item independently through `norm_tok`. Do not split arbitrary commas: commas may be filename/prose content, while brace sets and line references already have their own syntax.
2. **Resolver:** for `.ufo/*`, first test the lane path `$ROOT/$t`; if absent, retain the current fleet fallback `$ROOT/../.ufo/$r`. Keep `ufo/*` mapped to the fleet tree only. This matches the frozen C1 contract in `plans/round-24.md:23-25` while preserving a spelling for unambiguous fleet references.

## False-resolution risk and selftests to add
- A naive lane-first `.ufo/` lookup can make a dead, fleet-intended `.ufo/foo` appear live if a same-named lane-local file exists. The path alone cannot reveal intent. Keep/use the explicit fleet-only `ufo/foo` form for fleet citations (including labelled-dead fleet citations); migrate an ambiguous historical `.ufo/foo` citation if it was intended to name the fleet. Do not let a lane-side shadow satisfy `ufo/foo`.
- Add selftests: (a) two existing quoted comma-list entries resolve independently, exit 0; (b) one existing and one missing quoted list entry emits `UNRESOLVED` and exits 1; (c) lane-only `.ufo/...` target resolves, exit 0; (d) absent lane target with existing parent-fleet `.ufo/...` resolves via fallback, exit 0; (e) lane shadow exists but explicitly fleet-only `ufo/...` is dead and marked on its line—output must retain `LABELED` (not silently resolve through the lane shadow), exit 0. Also retain existing brace-set and line-reference cases unchanged.
