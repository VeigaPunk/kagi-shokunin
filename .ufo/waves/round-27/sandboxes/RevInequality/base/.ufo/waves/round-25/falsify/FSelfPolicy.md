# FSelfPolicy — self-count command and path boundaries

Revision tested: `82745e2c60e726b49499b8f309529935dc4eff2b` (fresh clone at `/fast/scratch/kagi-r25/FSelfPolicy/lane`). No installs.
Axes: command provenance; path confinement; recursion/process cleanup; C1 calibration.

## Verdict

**FAIL, conditional trust-boundary exposure (HIGH if run against an untrusted candidate tree; not a bypass in the declared trusted-repo model).** `self-counts.py` resolves a binding source to a row in `corpus/claim-ledger.tsv`, but it does not apply that ledger's command policy. Its `shell=False` only prevents implicit shell parsing; `bash -c`, `python3 -c`, and arbitrary Python/Bash wrapper scripts remain executable when their first token is allowed. The source comment explicitly limits this to trusted reviewed repo inputs (`self-counts.py:20-24`); therefore this is not evidence that the frozen default table runs hostile code.

**FAIL, conditional availability defect.** There is no self-counts recursion refusal. A data-table reference to committed row R25-02 (`claim-ledger.tsv:81`, command `python3 corpus/self-counts.py`) can re-enter the same tool if the default table resolves to that reference. `ledger_command` only detects `claim-ledger.sh` recursion (`self-counts.py:163-169`). A timeout on one `subprocess.run` does not itself kill a spawned process tree (`:181-191`). The frozen default table instead references R25-01's `--selftest` (`self-counts.tsv:21,37`), so this cycle is not activated by the shipped bindings.

**PASS, path confinement for data inputs.** A symlinked `--root` is canonicalized (`:370-373`); `repo_path` resolves document/rows paths and rejects paths outside that canonical root (`:70-80`). The external-table behavior is broader: a relative `--table` symlink escaping root is followed, despite the docstring describing absolute paths as the external-table selector (`:26-28,365,373`).

## Smallest remediation / limits

For untrusted trees, require the exact host-free command policy before any `ledger:` subprocess (including rejecting interpreter `-c` and unreviewed script paths); keep the trusted-repo caveat explicit otherwise. Refuse normal self-counts re-entry while retaining the exact R25-01 `--selftest` use, and use process-group cleanup for timeouts. Resolve relative `--table` paths and reject root escapes; keep the documented absolute external-table option. `c1-measure.sh` execution was **UNRUN**: it hard-codes `/fast/scratch/kagi-r25/XMeasureC1`, outside this seat's permitted sandbox; its source was inspected (`tools/c1-measure.sh:64-82,84-115`).
