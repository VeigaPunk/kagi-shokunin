### Instructions (how the capability is run)

- **Run the gate**: `python3 -I -B corpus/recheck-replay.py` from the lane root, or `--root DIR` over an extracted tree. Read-only, no network. It refuses (exit 2 SETUP) a symlinked `corpus/knowledge`, `corpus/SOURCES.md`, `corpus/recheck-captures.tsv` or `corpus/rendered-text-v1.py`; a symlinked knowledge entry is an UNSUPPORTED clock, so the gate cannot print CLEAN over it.
- **Prove the gate**: `python3 -I -B corpus/recheck-replay.py --selftest` — 20 cases at epoch D (18 at epoch C, 13 at epoch B), exit 0 with last line `RECHECK_REPLAY_SELFTEST: PASS (20 cases)`.
- **Run the claim counter**: `bash plans/round-56-c1.sh <revision>` or `--tree DIR`. Admission parses the `C1_REPLAY: value=<token>` line and requires `value=10`, `guard=1`, `present=10`; the counter exits 0 for `value=FAIL` and `value=0` too, so a rc-only harness is a defect (R56ReviewCounter F9).
- **Add a clock**: one column-1 `recheck:` line carrying a backticked `curl …` command in an accepted form followed by `-> N` or `-> count=N`; one row of `corpus/recheck-captures.tsv` (`id`, `url`, `body_path`, `fetched`, `http_status`, `bytes`, `sha256`); the id must name exactly one 11-cell `mined` `corpus/SOURCES.md` row whose source cell contains the URL; the body committed without any HTTP status line or `set-cookie:` line. Then run the gate and record the MATCH line; r5 requires the gate's summary to read `clocks=10`, so an added clock without its row turns the reading to 0 (control K1-F12).
- **Replace a capture**: public GET only (`curl -o`; never `-D`/`-i`), recompute `bytes`/`sha256` from the stored body, update the manifest row, re-run the gate; the replacement is a reviewed commit. The live run of the command is the currency check; the capture only makes the stated expectation checkable offline.
- **Repair a MISMATCH**: re-run the statement live. If the page moved, refresh the capture and row; if the entry's expectation was wrong, correct the N and record the date (never delete the clock silently). `NO-CAPTURE` means the clock is outside the gate (it cannot print CLEAN); `UNSUPPORTED` means the form is outside the three (the gate will not print CLEAN); `BAD-CAPTURE` names the path/digest/unconfinement/header defect; `TOOL` means a filter tool is missing or failed.
