# R67Sentinel — credential-shape scan (round 67)

Seat: `R67Sentinel` (sentinel). Lane `kagi-shokunin` (branch master). Claim BASE
`076701a11a58e3eb58d996b4c76c5e18071fb179`. Frozen plan `plans/round-67.md`
(landed `aa8807e443166f45485e1aada2989f646efc707c`).

Scope scanned: every file this round creates under `.ufo/waves/round-67/`, plus
every file the lane tree changed or added relative to BASE (tracked-modified
and untracked, `git status --porcelain --untracked-files=all`).

Tool: `python3 bin/credscan.py` (seat scratch) — regex classes; a match is a
SHAPE, never a confirmed secret. The scanner prints file:line and CLASS only.
Two shape refinements were applied after the BASE reference run so the counts
are honest rather than inflated:

- a base64-alphabet run lying entirely inside a hex digest is the same bytes
  as the hex class, not a second finding;
- a base64-alphabet run that is really a filesystem path (contains `/`, no
  `=`, ≥3 slashes) is a path, not a blob.
