## What the trial taught (beyond the five tests)

- OpenBao's refusal of an expired token reads `Code: 403 … permission denied`, not "expired" (K49ReviewerTrial probe-errs): an expiry claim rests on design isolation (only time changes), never on the error text.
- Batch tokens refuse revocation even by root, with the server's own reason `batch tokens cannot be revoked`; the refusal is a type property, not a permission gap.
- A token created without `-ttl` in dev mode gets 2764799 s (≈ 32 d − 1 s), the documented system max TTL default — so no observed non-root token is open-ended.
- T5 needs a contrast to mean anything: under a 30 m token the same 10 m lease survives the 5 s window; only the issuing token's lapse differs.
- The docs pages render `(non-<code>token</code>)` as `(non- token )` and insert U+200B after headings: a locator must use the rendered form (K49ExecSources).
